# QuickDict 英语单词查询插件 方案

## 背景
InkCanvasForClass 的师生需要在白板工具栏中快速查英语单词，且要适合触摸屏使用。现有商业方案封闭且功能有限；将 ECDICT、用户自主导入的 MDict 词典，以及 Edge TTS + Piper TTS 两种发音引擎结合起来，可以打造一个免费且体验更好的课堂查词插件。

## 改动内容
- 基于现有示例插件结构，开发新的 ICC 插件 `QuickDictForICC`。
- 在主工具栏注册一个按钮，点击后唤起触屏友好的查词弹窗。
- 在弹窗内实现虚拟键盘，方便触摸交互。
- 内置 ECDICT 作为默认查词数据源。
- 支持用户导入本地 `.mdx`（及可选 `.mdd`）MDict 词典文件。
- 实现两套 TTS 发音引擎：
  - **Edge TTS**：在线、免 API Key、高质量神经网络语音。
  - **Piper TTS**：本地离线、轻量、基于 ONNX，响应快。
- 查询结果展示音标、发音按钮、释义/词组/例句/近义词等标签页。
- 提供插件设置面板，用于配置词典路径、TTS 引擎、音色、语速等。

## 影响范围
- 受影响的 spec：ICC 插件清单、工具栏注册、服务注入、设置视图。
- 受影响的代码：新增插件项目替换示例插件；新增视图；新增词典与 TTS 服务层。

## 新增需求

### 需求：插件入口与工具栏按钮
系统应提供一个带有 `[PluginEntrance]` 标记的 ICC 插件入口，并注册一个工具栏项，用于打开查词弹窗。

#### 场景：成功打开
- **当** 用户点击主工具栏上的查词按钮
- **那么** 一个查词弹窗显示在白板主界面上方

### 需求：触摸屏虚拟键盘
系统应在查词弹窗内渲染一个虚拟 QWERTY 键盘，包含空格键、退格键和搜索键。

#### 场景：触屏输入
- **当** 触摸屏用户点击虚拟键盘按键
- **那么** 输入框累加字符，点击搜索键后触发查询

### 需求：内置 ECDICT 查词
系统应内置 ECDICT 数据，支持查询单词、音标、释义、词性、时态变化等信息。

#### 场景：查询成功
- **当** 用户输入并搜索一个已知英文单词
- **那么** 结果区显示单词、音标和简明释义

### 需求：用户导入 MDict 词典
系统应允许用户在设置面板中选择本地 `.mdx`（及可选 `.mdd`）词典文件并加载，加载后优先使用 MDict 查词。

#### 场景：导入并查词
- **当** 用户在设置中选择了有效的 `.mdx` 文件
- **那么** 插件加载该词典，并用它返回完整词条内容

### 需求：Edge TTS 在线发音
系统应使用 Edge TTS 作为默认在线发音引擎，支持美式/英式神经网络音色和语速调节，且不需要 API Key。

#### 场景：在线播放
- **当** 用户在联网状态下点击发音按钮
- **那么** 插件获取并播放该单词音频

### 需求：Piper TTS 离线发音
系统应支持 Piper TTS 作为离线备用方案，用户需自行下载 Piper 程序及语音模型。

#### 场景：离线播放
- **当** 用户在设置中配置了 Piper 路径和模型后
- **那么** 即使无网络也能本地合成并播放音频

### 需求：结果展示布局
系统应以标签页形式展示查询结果，至少包含：释义、词组、例句、近义词，并在底部提供"生成单词卡"按钮。

#### 场景：结果查看
- **当** 单词查询成功
- **那么** 用户可以切换标签页，点击发音按钮或生成单词卡按钮

### 需求：插件设置面板
系统应提供设置视图，包含：MDict 导入路径、TTS 引擎选择、Edge 音色与语速、Piper 路径与模型、缓存清理。

#### 场景：配置成功
- **当** 用户打开插件设置
- **那么** 所有可配置项均可见且可编辑

## 移除需求
### 需求：示例插件的演示组件
**原因**：示例插件中的演示工具栏项和设置视图只是占位功能。
**迁移方式**：移除 `RegisterSampleButton` 和 `RegisterSampleCustomControl`，替换为单个 QuickDict 工具栏按钮和新的设置视图。
